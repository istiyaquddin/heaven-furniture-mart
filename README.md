Heaven Furniture Mart is Chattogram's leading bespoke furniture atelier. Operating with zero flatpack items, every piece is built around the client's architectural floor plan, spatial proportions, and material preferences. The atelier uses exclusively seasoned hardwoods (**Burma Teak** & **Gamari** dried to an 8–12% moisture standard) paired with European damask silks, fluted velvets, and full-grain Italian leathers.

## 🚀 Local Development

```bash
# Clone the repository
git clone https://github.com/istiyaquddin/heaven-furniture-mart.git
cd heaven-furniture-mart

# Install dependencies
npm install

# Run the development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

Open `http://localhost:3000` in your web browser.

## 🌐 Deploy to Vercel

```bash
# Deploy to production via Vercel CLI

```

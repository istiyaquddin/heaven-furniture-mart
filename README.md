## 🛠️ Technology Stack

- **Markup & Semantics:** Semantic HTML5, Schema.org LocalBusiness structured data.
- **Styling:** Tailwind CSS (CDN) + Custom Editorial Minimalist CSS (`Playfair Display`, `Montserrat`, glassmorphism, gold hairline borders, luxury animations).
- **Icons:** Google Material Symbols Outlined & inline SVG luxury social icons.
- **Interactions:** Pure Vanilla JavaScript (zero heavy external framework dependencies).
- **Responsive Breakpoints:** Fully fluid and tested across 375px (Mobile), 768px (Tablet), 1100px (Laptop), and 1440px+ (Desktop).

## 🚀 Local Development

Clone the repository and launch a static web server:

```bash
# Clone the repository
git clone https://github.com/istiyaquddin/heaven-furniture-mart.git
cd heaven-furniture-mart

# Serve locally
npx -y serve . -p 3000
```

Open `http://localhost:3000` in your web browser.

---

## 🌐 Deployment to Vercel

Deploy instantly with the Vercel CLI:

```bash
# Install Vercel CLI (if not installed)
npm i -g vercel

# Deploy to production
vercel --prod
```

Or connect the GitHub repository directly in your [Vercel Dashboard](https://vercel.com/new).
